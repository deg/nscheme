λ nscheme

An R7RS Scheme interpreter written in Rust, running in this page as WebAssembly. The R7RS-small core plus the R7RS-large libraries — try (import (scheme list)). Source on GitHub.

Files your programs write are saved in this browser. Run one with
      (load "prog.scm"); a library saved as lib/mine/greet.sld is
      (import (mine greet)).

  


  

    
Every entry is evaluated in the same session, so definitions build up until you press
      Reset. Entries run in the background: Stop ends one that runs too long, and starts a
      new session. Files are saved in this browser; there is no keyboard input yet.
